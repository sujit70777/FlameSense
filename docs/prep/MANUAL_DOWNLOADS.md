# Manual downloads (PSI) — login required

Generated by `scripts/download_psi.py` on 2026-11-02.

PSI's anonymous API serves the public metadata and file lists, but every file-content route
(`/geode-py/ws/source/file`, `/studies/<id>/download`) answered **403** without a login. The
script did not log in or try any other route. A human with a free PSI account should
download the files below from the investigation page and save them **without renaming** into
the target folder, under the same sub-path shown in `files_manifest.csv` (`folder` column),
inside `files/`. Re-run the script afterwards: it records checksums and marks them downloaded.

Priority 1 = experimental table (test matrix). Priority 2 = other tables. Priority 3 = small
documents. Large videos, images and archives are not listed here (see each manifest).
